# Paradise Nursery 🌿

A React + Redux houseplant shopping application created as a Coursera practice/final project.

## Features

- Landing page with background image, company information and Get Started button
- Product listing page with 18 houseplants across 3 categories
- Add to Cart functionality with disabled buttons after adding
- Dynamic cart quantity in the navbar
- Shopping cart with increase, decrease and delete controls
- Automatic item totals and overall cart total
- Continue Shopping navigation
- Checkout button with "Coming Soon" message
- Responsive design for desktop, tablet and mobile

## Tech Stack

- React
- React Router
- Redux Toolkit
- React Redux
- Vite
- CSS
